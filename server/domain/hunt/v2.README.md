# Hunt v2 engine

## 1. Purpose

`server/domain/hunt/v2.ts` is the authoritative rule engine for the redesigned single-whale, single-tracer game. It creates varied deterministic fallback boards or consumes a server-provided live board factory, applies Burst, Drip, Blend, Decoy, and Late push, resolves six evidence lanes, controls deadlines, awards one point per round, and ends a match at three points.

## 2. Functions and methods

- `HuntV2Engine.createMatch` creates a persisted v2 match and first round.
- `getMatch` applies overdue persisted transitions and builds the actor-specific view.
- `command` validates role, phase, state version, idempotency, plan, scan, catch, and forfeit commands.
- `rematch` creates a fresh match with the player's role swapped.
- `tick` provides a restart-safe deadline entrypoint.
- `HuntV2Error` reports structured rule and transport failures.
- `movePulseIndices` (`server/domain/hunt/v2.ts:116`) scales each whale action's pulse pattern to the chart length.
- `baseWindows` (`server/domain/hunt/v2.ts:129`) creates varied synthetic regimes for fallback mode.
- `applyMove` (`server/domain/hunt/v2.ts:162`) layers the selected whale action and decoy onto the public curves.
- `scanResult` (`server/domain/hunt/v2.ts:359`) returns Flow, Concentration, Rhythm, Timing, Cross-asset, and Position growth evidence.
