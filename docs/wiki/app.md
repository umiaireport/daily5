# `server/app.ts`

`buildApp` (`server/app.ts:32`) creates Fastify, initializes daily SQLite tables and private settlement sources, registers cookies/rate limiting, security and origin hooks, controlled errors, session/game routes, daily challenge summary/entry/result routes, health/admin status, and optional `dist/` serving. `sessionId` (`server/app.ts:142`) requires the cookie and verifies it through `Game.session`. `dailySummary` (`server/app.ts:282`) returns only the pinned public evidence and lifecycle state, while `ensureDailyChallenge` (`server/app.ts:306`) publishes an immutable UTC-day challenge on first startup. Routes and response semantics are listed in [`../api-map.md`](../api-map.md); automated provider settlement runs in the one-shot worker under an external scheduler.
