# `web/components/Arena.tsx`

`Arena` (`web/components/Arena.tsx:12`) renders the three token cards and decision controls. `adjust` (`26`) moves 10-point allocation increments between an asset and cash. `openClue` (`35`) reuses an opened clue or requests a server unlock. The component also renders two-credit status, source-specific labels, clue timestamps, cash-only confirmation, and lock action.
