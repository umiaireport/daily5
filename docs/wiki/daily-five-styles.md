# Daily Five styles

## 1. Scope

`web/daily-five.css` styles Daily Five only. Root main/state receives page padding and maximum width; nested chart namespace classes no longer repeat page spacing.

## 2. Sections

Capital/progress, A–E buttons, compact colored chart snapshots, chart/evidence, segmented allocation bar, leverage fields, ticket controls, feedback/countdown, contribution reveal cards, final scorecard, and responsive overrides. Desktop uses two columns. Mobile uses five compact buttons and an inline commit strip that never covers controls. Visible focus, 44px controls, pressed states and reduced motion are explicit. No functions are declared.
