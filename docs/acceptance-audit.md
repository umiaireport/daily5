This audit records the September 17, 2026 state of the checkout. It distinguishes the implemented no-key synthetic tutorial, the verified live replay path, and the external release obligations that still need a human-owned public identity.

## 4. Recheck commands

From `whale-arena/`, use `./dev.sh` for local development or installed Node 24 with the checked-in lockfile. The documented commands are `npm run format:check`, `npm run typecheck`, `npm test`, `npm run build`, and `npm run test:e2e`; use `CHROMIUM_PATH` or `npx playwright install chromium` when the configured browser is unavailable.
